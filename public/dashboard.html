Setup Instructions
1
Add Browser Source

In OBS, add a new Browser Source. Name the source "Wildcat TTS" and paste the copied URL. You can keep the default width and height.

2
Control Audio via OBS

Select Control audio via OBS. Make sure that Shutdown source when not visible is not selected.

3
Monitor and Output

In the OBS Audio Mixer, find "Wildcat TTS". Click the gear icon and select Advanced Audio Properties. Set Audio Monitoring to Monitor and Output.
