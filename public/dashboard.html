Setup Instructions
1
Add Browser Source

In OBS, add a new Browser Source. Name the source "WildcatTTS" and paste the copied URL. You can keep the default width and height.

2
Control Audio via OBS

Select Control audio via OBS. Make sure that Shutdown source when not visible is not selected.

3
Monitor and Output

In the OBS Audio Mixer, find "WildcatTTS". Click the gear icon and select Advanced Audio Properties. Set Audio Monitoring to Monitor and Output.

    Expand Chat Acronyms

    TTS expands common Twitch acronyms into words. For example, “ngl” becomes “not gonna lie”. Turn off to spell out each letter.

    Profanity Filter

    TTS replaces profanity with milder words before speaking. The filter uses the channel language and the viewer language. If language is set to Automatic, the filter uses the English list. Banned words still skip the full message.
